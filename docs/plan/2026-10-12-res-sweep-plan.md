# Plan: resolution sweep 512→1024 px (ASL vs entropy gate) + short Markov/patient-metadata section

## Context
At 512 px, 6 seeds, the entropy gate gave no gain over ASL-only, no-gate or random-gate (C−B −0.0014 [−0.0048,+0.0021]; MDE ≈0.005). The user wants to look for a setting where the gate separates from ASL: a resolution sweep from 512 to 1024 px with other seeds. Resolution was the strongest lever in earlier sweeps (512/640/768/1024 ≈ 0.443/0.449/0.456/0.462 for the gate arm), but no ASL-only control was run on the same code path except 768 px (v5 code, 2 seeds: indistinguishable from the gate). The user also wants the 4-page paper to carry a brief Markov-with-patient-metadata section (with the two Markov figures from `docs/paper/markov/paper.pdf`) using existing checkpoint metrics. Page 3 of `isbi_submit/paper.pdf` now ends the technical content at y≈510, so about 0.4 page is free before page 4 fills; references may move to page 5 (allowed), technical content must stay ≤ page 4.

User decisions (2026-10-12): sweep = arms A (ASL-only) and C (entropy gate), resolutions 640/768/896/1024 px, 3 seeds; Markov part = short paragraph from existing numbers, plus Fig. 1 (where the priors enter) and Fig. 2 (post-prediction patient HMM) from the Markov paper. No new Markov runs.
